# genfeat-mri docs vault

Open this folder in Obsidian: **Open folder as vault** → select `docs/vault/`.

- **Canonical docs** remain in the parent [`docs/`](../) directory.
- **Mermaid** diagrams use Obsidian's built-in Mermaid support (enabled by default).
- **Code links** use relative paths to the repository root (`../../../tolkien/...` from nested notes).
